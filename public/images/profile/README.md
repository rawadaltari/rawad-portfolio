# Profile photo

Place your portrait here as **`rawad-altari.jpg`** (this exact name).

- Recommended: portrait 4:5 ratio, at least 832×1040 px, under ~250 KB (export as high-quality JPG or WebP).
- It appears automatically in the hero — no code change needed.
- To use another file name or format, change `profileImage` in `src/config/site.ts`.
